⚙️ Laravel Backend
drybox:poll scheduler — every 1 minute
  • Reads Firebase via kreait SDK
  • Stores readings → MySQL
  • Runs AlertEvaluator rules
  • Creates alert records
  • Dispatches SendGmailAlert jobs
  • Writes protection_mode → Firebase
